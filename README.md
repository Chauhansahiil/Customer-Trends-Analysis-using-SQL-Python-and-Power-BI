# Customer Shopping Behavior Analysis

An end-to-end data analytics project on retail customer and shopping data. The raw data is cleaned and explored in **Python (Pandas)**, loaded into a **SQL** database to answer business questions about customer segments, loyalty and purchase drivers, and presented in an interactive **Power BI** dashboard.

**Tools:** Python, Pandas, SQL, Power BI

## Project Overview

The goal is to work through the full workflow of a business data analyst, from raw data to insights a stakeholder can act on.

- **Data preparation and EDA (Python):** import, explore and clean the raw dataset.
- **Business analysis (SQL):** load the cleaned data into a database and run queries on customer segments, loyalty and purchase drivers.
- **Visualization (Power BI):** build an interactive dashboard showing key patterns and trends.
- **Report:** summarise the findings and recommendations.

## How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/Chauhansahiil/REPO_NAME.git
   cd REPO_NAME
   ```
2. **Open the notebook** `Customer_Shopping_Behavior_Analysis.ipynb` and run the cells to import, explore and clean the data.
3. **Load the data into a SQL database** (MySQL, PostgreSQL or MS SQL Server): create a database, run the notebook code that loads the data, then run `customer_behavior_sql_queries.sql`.
4. **Connect Power BI to the database** and open `customer_behavior_dashboard.pbix`.
